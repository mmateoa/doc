# CHAMB-IA

Proyecto Android Java con rediseño UX/UI.

- [Descargar el proyecto actualizado (ZIP)](../../raw/refs/heads/master/entregas/ChambIA_UX_UI.zip)
- [Abrir el código Android](ChambiaRe/)
- [Reporte de implementación y pruebas](ChambiaRe/docs/UX_IMPLEMENTATION_REPORT.md)

Para trabajar en Android Studio, descarga el ZIP y abre la carpeta `ChambiaRe`. Requiere JDK 17 y Android SDK 35. Para actualizar una instalación existente, usa tu firma habitual; no desinstales la app para resolver un conflicto de firma.

El reporte distingue las funciones implementadas y probadas de las verificaciones pendientes en dispositivos (USB, TTS, TalkBack y otros tamaños).
