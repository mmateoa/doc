# CHAMB-IA

Proyecto Android Java con rediseño UX/UI.

- [Descargar el proyecto actualizado (ZIP)](https://github.com/mmateoa/doc/raw/refs/heads/master/entregas/ChambIA_UX_UI.zip)
- [Abrir el código Android](ChambiaRe/)

Descarga el ZIP y abre `ChambiaRe` en Android Studio. Requiere JDK 17 y SDK 35. Usa tu firma habitual para actualizar una instalación existente sin desinstalarla.

Esta edición pública incluye código, pruebas, capturas y muestras ficticias. Omite registros de máquina y rutas locales. Los resultados y pendientes están en el reporte.
